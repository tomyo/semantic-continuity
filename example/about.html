About This Web Strategy

This example distinguishes between enhanced structures and runtime-owned custom elements. This is a local project convention, not a universal component ontology.

  • Enhanced structures (enhance.js) attach optional behavior to HTML that already exists and remains inspectable.
  • Runtime-owned custom elements (component-name.js) use customElements.define when the component must create or manage runtime UI.

The <live-chat> widget is deliberately runtime-dependent. Its continuity requirement is explicit ownership and failure behavior, not a claim that it has the same static baseline as the document content.
